# ClickHouse export

1. Перед выгрузкой проверь нетривиальный SQL через `dwh_ch_query_test`. Структуру незнакомых таблиц получи через `dwh_ch_table_ddl`.
2. Не выгружай персональные данные: ФИО, контакты, адреса, документы, платёжные данные, идентификаторы клиентов и сотрудников. Замени их агрегатами или уточни задачу.
3. Вызови `dwh_ch_export` с параметрами:
   - `sql` — один читающий SELECT, можно с CTE;
   - `output_path` — абсолютный путь в папке текущей задачи; расширение `.csv`, `.parquet` или `.xlsx`;
   - `format` — `csv`, `parquet` или `excel`;
   - `alias` — контур ClickHouse, если пользователь его указал;
   - `chunk_size` — по умолчанию 10 000, допустимо 1–100 000;
   - `delimiter` — только для CSV, по умолчанию запятая; для табуляции передай `\t`.
4. Жёсткий лимит — 1 000 000 строк. При превышении файл удаляется: не повторяй тот же запрос, а предложи непересекающиеся диапазоны или более строгий фильтр.
5. Не запускай повторно после таймаута или неясной ошибки без подтверждения пользователя: исходный запрос мог продолжить выполняться. Экспорт специально не повторяется автоматически.
6. Существующий файл не перезаписывается. Для новой выгрузки выбери другое имя; не удаляй пользовательский файл самостоятельно.
7. После успеха верни пользователю путь, формат, фактическое число строк и размер из JSON-результата. Не утверждай, что файл создан, при ошибке инструмента.

CSV пишется в UTF-8 с BOM. Parquet использует сжатие Zstandard. Excel содержит один лист `export`.
