---
name: sql
description: Гайдлайн написания sql-скриптов. Вызывать, когда задача содержит написание sql-скрипта. Не перечитывать.
---
1. Скрипт всегда в lowercase, даже системные слова
2. Поля таблиц в greenplum, написанные в camelCase следует обрамлять в ковычке (регистрозависимые)
3. Скрипт не должен содержать пустых строк; пустые строки должны быть закомментированны, если требуется отделить смысловые блоки.
4. Запятые, союзы стоят в начале следующей строки, например:
```sql
select
    ds_id
    , date
from table 
where date between :date_from and :date_to
    and ds_id = :ds_id
```
5. В шапке скрипта в комментариях пишется краткое описание (Номер задачи, назначение, затрагиваемые источники)
6. У пользователя есть инструмент выполнения .sql запросов.
7. Уберай alias в последнем select, например: t.ds_id as ds_id
8. Не следует использовать переменные в запросах на выгрузку данных: они предполагают подход без транзакций. Параметризация обеспечивается в CTE либо в параметрах %(param)s
